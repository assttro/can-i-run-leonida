Sources

Hardware ranges use community predictions and general PC benchmarks. They have not been validated in Leonida gameplay. All four console comparisons use the admin’s approximate PC equivalents. The admin suggests 32 GB DDR4 and expects DDR5 to be suitable. DDR4 below 32 GB remains uncertain in console comparisons. DDR5 uses 16 GB as a provisional capacity floor, with smaller amounts marked uncertain. These RAM assumptions are untested in Leonida. Console shared memory and PC RAM are different arrangements. PS5 Pro estimates vary with the game and upscaling mode. Laptop parts are compared with the closest desktop model from Notebookcheck’s mobile benchmark lists; power limits and cooling vary between laptops, so these results are approximate.
